# Security policy: Wiki.js build kit

To report a vulnerability in this build kit or in the `readystack/wikijs` image, email support@readystack.dev (the contact in https://readystack.dev/.well-known/security.txt). Please do not open a public issue for it.

A vulnerability in Wiki.js itself belongs with its upstream project (https://github.com/requarks/wiki); ReadyStack ships upstream's fix in its next release.

Every ReadyStack release is scanned again every day; known defects of each release are in this repository's Issues and at https://readystack.dev/defects.html?product=wikijs.
